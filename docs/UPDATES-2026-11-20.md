# 2026-11-20：鲁棒性扰动实验全量评测、Agent 状态机 v2 升级与检索层增强修复

本轮迭代聚焦于两项核心目标：一是执行并补全 `PROJECT_REPORT.zh-CN.md` 6.1 节中长期标为“未执行”的
预选 8 题四类扰动全量基准实验；二是基于评测中捕获的真实失分病例与断言缺陷，对评测层、Agent 控制层
及底层检索层实施全链路修复优化，策略版本升级为 `verified-targeted-repair-v2`。

## 发现的问题与病因诊断

1. **测试与评测客户端代理劫持（`eval/run.py`）**：宿主机开启系统代理软件（如 VPN/学术代理）时，
   `urllib.request.urlopen` 请求 `127.0.0.1` 触发 `HTTP 502 Bad Gateway`，导致自动化测试中
   `test_async_api_client_does_not_send_gold` 出现异常失败。
2. **A0 短答案字面包含过度误杀（`app/agent.py`）**：`probe3` 验证表明，当答案为 `"1,500 requests per second"`
   而陈述为 `"1500 requests per second"` 时，因千分位逗号被字面正则判定为 `answer_mismatch`，
   白白耗尽修复预算并导致误拒答。
3. **补检索状态机反馈断层与死锁（`app/agent.py`）**：
   - **重起草失忆**：在补检索获取新证据后，调用 `draft()` 时未透传前序检查器给出的 `failed_claims`
     与失败原因，导致模型盲目重生成。
   - **逻辑纠错放弃**：在 HotpotQA `5adc020a` 任务中，检查器已明确指出“Webb 仅为编剧并非作者，推导
     '均为作者' 证据不足”，但当补检索没有召回新文档时，原系统直接触发 `no_new_evidence` 中止并拒答，
     缺少基于现有证据由模型更正结论（将 `Yes` 修正为 `No`）的自愈机制。
   - **无约束工具误调**：`decide(repair=...)` 缺少针对性修复提示，在 `allow_web=False` 场景下仍偶发
     尝试调用 `search_web`（如 `5a7e0563` 触发 blocked 调用）。
4. **问答目标一致性穿透（`app/agent.py`）**：在 `5a7e0563` 中，题目询问“被捕月份与年份”，模型将
   “死亡时间（June 2017）”填入答案，原检查器仅核实该段落是否提及该日期，未校验答案陈述是否真正针对
   所提问题，导致答非所问穿透门禁。
5. **底层文件查看工具的分页与匹配死锁（`app/retrieval.py`、`app/store.py`）**：
   - `view_file`（`read_file`）在面对句子切块（HotpotQA）或按页切块（PDF）等非行结构文档时，
     无论模型传入何种 `start_line` / `end_line` 翻页区间，均硬编码返回 `candidates[:8]`，
     导致第 8 个片段之后的内容永远无法被 Agent 查阅；
   - 标题检索区分大小写且无扩展名容错，当 Agent 传入省略 `.md` / `.txt` 的文件名时查询直接失效。

## 核心优化与修复

- **评测直连隔离（`eval/run.py`）**：在 `request_json` 中对 `127.0.0.1`、`localhost` 及 `::1`
  显式绑定空代理处理器 `ProxyHandler({})`，彻底杜绝宿主机系统代理劫持。
- **A0 门禁规范化与目标一致性校验（`app/agent.py`）**：
  - 引入 `_normalize_for_answer_match`，对数值千分位逗号、百分号前空格及连续空白实施规范化；
  - 强化 `verify()` 提示词，明确要求 `A0` 陈述必须核对是否与题目目标事件/实体严格对齐，拦截时空错位答案。
- **闭环自我修复状态机升级（`app/agent.py`）**：
  - 补检索重起草支持接收 `previous_feedback`，保持前序证据批判上下文；
  - 新增 `REPAIR mode` 专属规划提示词，强制优先参考 `failed_claims.reason` 与 `suggested_queries`，
    并在禁用联网模式下强硬锁死网络工具调用；
  - 引入 `reasoning_repair_rounds` 机制：当证据已齐备但结论逻辑被检查器否定时，允许进行一次免补检索的
    反思重草拟，消除因无新文档而过早放弃的死锁。
- **检索与存储层增强（`app/retrieval.py`、`app/store.py`）**：
  - `document_chunks` 引入 SQLite `COLLATE NOCASE`，支持大小写不敏感标题查找；
  - `read_file` 支持常见扩展名回退识别，并为非行切块文档引入基于 `start_line` 的片段窗口偏移分页。
- **配置策略版本演进（`app/config.py`）**：策略版本正式更新为 `verified-targeted-repair-v2`。
